# playwithclaude

A workspace for tasks built with Claude Code. Each task lives in its own
folder, `<category>/<task-name>/`, with its own README. Category folders
(java, security, web, python, scripts, career, learning) are created when
the first task needs them. Rules are in [CLAUDE.md](CLAUDE.md).
